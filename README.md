E-Commerce Cart Application

A full-stack cart-based web application built using **React (Frontend)** and **Express.js + Node.js (Backend)** with **MongoDB** as the database.  
This project demonstrates product management, cart functionality, and smooth frontend-backend integration.

Features-
Add to cart / Remove from cart
Persistent cart data stored in database
Responsive UI using modern React setup
REST API backend using Express.js

Tech Stack
 Layer      Technology 
Frontend  React, JSX, CSS, Axios
Backend  Node.js, Express.js
Database  MongoDB / Mongoose 
Version Control - Git & GitHub

Project Structure
E-com-Cart/
├── frontend  -React UI
├── backend   -Express API

How to use :-
  git clone https://github.com/your-username/E-com-Cart.git
  cd E-com-Cart

Install Frontend Dependencies
  cd frontend
  npm install

Install Backend Dependencies
  cd ../backend
  npm install

Create .env file in backend (example)
  MONGO_URI=your_mongodb_url

Run Both Servers

Backend:

cd backend
npm start

Frontend:
cd ../frontend
npm start
